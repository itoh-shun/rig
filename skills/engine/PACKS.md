# rig — pack 詳細目録

**SKILL.md §2「pack 追加分」の長文説明の正本。** §2 本体はブリック名と1行要旨だけを持ち（起動時に必ず読まれるため context-minimal を優先）、各 pack が何をするかの詳細説明はこのファイルに置く。**pack の挙動そのものの正本は各 instruction / recipe / pattern ファイル**であり、本ファイルはそこへ辿り着くための索引＋設計意図の記録。

新しい pack を足したら **§2 の1行要旨と本ファイルの詳細行の両方**に追記する（`--validate` は §2 とファイル実体の突き合わせを検査するため、§2 からブリック名を落とすとドリフト検出が効かなくなる）。
