# instruction: layout-measure

宣言した検査を実行し、その出力をそのまま次へ渡す step です。判断はしません。

## 手順

1. `./scripts/layout-gate.sh` を実行します。
2. 終了コードと標準出力・標準エラーを、加工せずに記録します。
3. 落ちたときは、溢れと重なりの一覧が出力に含まれます。件数と場所を要約せず、そのまま
   残します。reviewer はこの行を根拠に使います。

## ガード

- 出力を読みやすく書き直しません。件数を丸めません。
- 落ちた検査を、実行し直して通るまで繰り返しません。直すのは前の step です。
- 検査そのものが起動しなかったとき（script が無い、Playwright が無い、生成器が落ちた）は、
  合格でも不合格でもなく**未検査**です。そのまま伝えます。
