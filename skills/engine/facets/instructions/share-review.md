# instruction: share-review

報告ファイル、ページ、材料を突き合わせ、公開してよいかだけを判定する step です。判定は
`share-page-reviewer` へ委譲します。

## 手順

1. `.rig/share-check-report.json` を読み、`status` が `checked` で `errors` が 0 かを
   確かめます。
2. ページの数字・日付・固有名詞を材料と照らし、出典の無いものを挙げます。
3. 秘密情報、個人情報、社外秘の識別子、装い、本人が決めていない事柄が無いかを見ます。
4. warning のうち直さなかったものに理由があるかを見ます。
5. `share-page-verdict` の形で判定だけを返します。

## ガード

- ページを直しません。read-only です。
- 文体や配色の好みを指摘しません。範囲を広げません。
- 印象を根拠にしません。根拠は報告の行、ページの箇所、材料の箇所です。
- 検査が走っていないときは `UNVERIFIED` です。走らなかったことを合格に読み替えません。
