# instruction: japanese-write

日本語の完成稿生成を `japanese-writer` へ委譲する routing です。文章の品質規則をここへ
重複させず、workflow の境界は `writing-delivery-contract`、日本語と内容の規則は
`japanese-writing-rules-v2` に委ねます。

## 手順

1. 入力から、目的、読み手、掲載先、明示された事実、指定された文体と禁止事項を抽出します。
2. 完成稿に不可欠な情報が欠け、対話できる場合は、執筆前に結果を変える一点だけを確認します。
   対話できない場合は推測せず、与えられた事実だけで成立する表現にします。
3. `japanese-writer` を別 subagent に dispatch し、二つの policy を末尾へ順に合成します。
4. 完成稿を一つだけ受け取り、自己採点させず `japanese-writing-review` へ渡します。

## ガード

- 同じ依頼に対する候補案を並べません。
- 入力にない背景、感情、因果、数値、期限を埋めません。
- 入力に秘密情報があっても値を完成稿へ移しません。`[REDACTED]` に置き換え、必要なら
  非秘密の診断情報だけを最小限に依頼します。
- 下書きに誤りが疑われても黙って事実を置換しません。確認できなければ断定を避けます。
- 生成者の「問題ありません」という自己申告を review の代わりにしません。

## 出力の終端

- 応答は想定読者が最初に読む完成稿の本文から始め、完成稿の最後の文で終えます。
  生成過程や適用 policy の説明、本文と補足を分ける区切り線、追加調整の申し出を前後に置きません。
