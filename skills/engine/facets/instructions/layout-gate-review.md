# instruction: layout-gate-review

検査の出力と成果物を突き合わせ、出荷してよいかだけを判定する step です。判定は
`layout-gate-reviewer` へ委譲します。

## 手順

1. 検査が実際に走ったかを、実行した出力で確かめます。
2. 溢れ・重なり・切れが残っていないかを、出力の行から確かめます。
3. 合格させるために本文が削られていないか、許容誤差が広げられていないか、検査が
   外されていないかを、差分から確かめます。
4. `layout-gate-verdict` の形で判定だけを返します。

## ガード

- 資料を組み直しません。read-only です。
- レイアウト以外（言い回し、構成、事実関係）を指摘しません。範囲を広げません。
- 目で見た印象を根拠にしません。根拠は検査の出力にある行です。
- 検査が走っていないときは `UNVERIFIED` です。走らなかったことを合格に読み替えません。
