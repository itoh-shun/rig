# output-contract: design-verdict

## output-contract: design-verdict

UI/UX・a11y レビュー担当（`design/ux-reviewer` / `design/a11y-reviewer`）が共通で遵守する出力構造。**evidence-first**：所見・条件を先に書き、判定は最後に置く（判定を先に出すと理由付けの前に結論へコミットするため）。機械抽出は**末尾**の `判定:` 行（最後に現れる `判定:` 行）から行う。前置き・挨拶・補足説明は禁止する。

### 形式

```
制約 所見:
状態: <checked|unchecked|not-configured>（unchecked / not-configured のときは理由も1行で）
1. [クラス: raw-value|unknown-token|unknown-component|prohibited-expression] （該当箇所・宣言との差・use か mention か・どう直すか）
2. …

UI/UX 所見:
1. [重大度: 高|中|低] （所見・該当箇所・なぜ問題か・どう直すか）
2. …

a11y 所見:
1. [WCAG <達成基準番号> / レベル <A|AA|AAA> / 重大度: 高|中|低] （該当箇所・違反内容・具体修正）
2. …

条件:
【対応必須】
- （リリース/採用前に必須。なければ省略）
【フォローアップ可】
- （任意・後続対応。なければ省略）

判定: <APPROVE|REJECT|APPROVE_WITH_CONDITIONS>
```

### ルール

- **所見を最初に出力する**（evidence-first）。判定より前に、制約 所見・UI/UX 所見・a11y 所見を必ず書く。判定から書き始めてはならない。
- **制約 所見は `ux-reviewer` が担当する**（`a11y-reviewer` は「制約は担当外」と明記し、WCAG 上の問題でもある違反は `a11y 所見` 側で基準番号つきに書く）。
- **制約 所見の1行目は必ず `状態:`**。`policies/design-constraint-rules` の3状態を**言い換えない**。`unchecked`（宣言はあるが検査が成立しなかった）と `not-configured`（宣言が無い）を、**合格・「指摘なし」・「問題なし」と書いてはならない**。センサーが走っていないなら、走っていないと書く。
- センサーの `violations` は**証拠であって判定ではない**。センサーは use と mention を区別しないので、各項目について reviewer が「実際に使っているのか、過去の値に言及しただけか」を判定して書く。mention と判断したものは、そう書いて落とす（黙って消さない）。
- 逆に、**「違反 0 件」を「制約を守っている」と書かない**。センサーはトークン化されていない散文（「ブランドの青を使う」）を構造的に検出できない。そのクラスは reviewer が読んで判定する。
- **判定は末尾に必ず出力する**（`判定:` で始まる行。最終行）。所見の本文中で判定行を引用してもよいが、機械抽出は**最後に現れる** `判定:` 行を採用する。判定語は `APPROVE` / `REJECT` / `APPROVE_WITH_CONDITIONS` のいずれか（従来と同一の語彙・意味）。
- **UI/UX 所見**は各項目に重大度を付す。`ui-ux-heuristics` の観点名を可能な限り名指す。所見なしなら「指摘なし」の1行。
- **a11y 所見**は各項目に **WCAG 達成基準番号・レベル・重大度** を付す。`a11y-wcag` の基準を名指す。所見なしなら「指摘なし」の1行。
- 目標 WCAG レベル未達（既定 AA）の違反が1つでもあれば判定は `APPROVE` にしない（`REJECT` または `APPROVE_WITH_CONDITIONS`）。
- **制約違反が1件でも残っていれば判定は `APPROVE` にしない**（`REJECT` または `APPROVE_WITH_CONDITIONS`）。`状態: unchecked` のときも `APPROVE` にしない——検査が成立していないものを合格にしない。`状態: not-configured` は宣言が無いので判定を拘束しないが、**その事実を書かずに済ませてはならない**。
- 条件は「対応必須」と「フォローアップ可」を分け、該当なしのサブブロックはヘッダごと省略。両方なければ `条件:` 全体を省略。
- 各所見は「どこの・何が・なぜ・どう直すか」が分かる粒度。空ワード・感想・締め挨拶は禁止。
