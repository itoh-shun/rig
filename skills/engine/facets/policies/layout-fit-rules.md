# policy: Layout Fit Rules v1

生成した資料を「見て確かめる」のをやめて、機械に測らせるための規則です。対象は、箱の位置と
大きさを自分で決めて描く成果物（スライド、カード、固定サイズのページ）です。

## 測ってから出す

1. 箱を置くときは、**幅・高さ・座標を数値として宣言します。** どこかに残らない見積りは
   検査できません。
2. 中身を入れたら、**折り返し後の必要量を計算して、宣言した箱と突き合わせます。** 文字数
   ではなく行数で見ます。
3. **1 件でも入りきらなければ、成果物を書き出しません。** 書き出してから直すのではなく、
   書き出さないことで、壊れたファイルが残らないようにします。
4. 検査を通ったことは、実行した出力で示します。「確認しました」という自己申告を、検査の
   代わりにしません。

## 何を見るか

- **高さ** — 折り返し後の行数 × 行送り。見出しがあるときは、見出しの**実測した高さ**から
  本文の開始位置を決めます。固定値で確保しません。
- **幅** — 折り返さない塊（コード、表のセル、等幅の行）の最長行。
- **切れ** — `overflow: hidden` の中で黙って切れている行。`scrollWidth` と `clientWidth` の差。
- **重なり** — 同じページに置いた矩形どうしの交差。片方がもう片方に完全に含まれる入れ子は
  除きます。

## やらないこと

- **合格するために本文を削りません。** 入らないときは、まず枠を広げるか、ページを分けるか、
  文を短くするかを選びます。選んだことは報告します。黙って情報を落としません。
- **許容誤差を、落ちたから広げることはしません。** 見積りの誤差のために少しだけ持たせる
  値であって、落ちた分を通すための値ではありません。
- **検査を外して通しません。** 一時的に外すなら、外したこととその理由を報告に書きます。
- **文字幅の近似を、余白の最適化に使いません。** 実際のフォントのメトリクスではないので、
  「あと 0.05 インチ空いている」といった判断には足りません。

## 検査できないとき

Playwright や Chromium が無い、生成器が動かないなど、検査そのものが走らなかったときは、
**未検査として報告します。** 走らなかったことを合格として扱いません。この区別が消えると、
ゲートは何も守らなくなります。

原因の分類は `[[layout-overflow-causes]]` にあります。
