# クロージングと反論処理

クロージングとは「**白黒をつける**」ことと、「**最後の背中を押す**」ことの2つを指す。

重要な前提: **クロージングは前工程が終わっている前提の技術。** 不満の顕在化 → 解決策の提示 → 小さな合意の積み上げ、をやらずに「それではこれでよろしいでしょうか」と言えば「急に何の話だ」になる。しかも、そこまで到達できているかどうかを自分で判定できていない営業も多い。→ [sales-discovery-questioning](sales-discovery-questioning.md)

## 1. 終わり方（ゴール）を先に決める

商談の終わり方を、良い順に定義していない営業は方向を出せない。定義できる終わり方は実質**この4つしかない**。

1. 申し込み
2. **お断り**（白黒がついた）
3. 相手に宿題を渡し、次回＝申し込みのアポイントを取る
4. 相手に宿題を渡し、次回＝手続きに必要な工程と申し込みがセットのアポイントを取る

> 「検討して、こちらからご連絡します」は**この4つのどれでもない**＝終わり方になっていない。

「うちの商談の終わり方は4つ、何と何？」と聞いて答えられない営業は、まずここから始める。ゴールが定義されていないと、商談中に「今どこにいるか」も判定できない。

## 2. クロージングはキャッチボールである

```
営業:「これで進めませんか」（ボールを投げる）
客 :「今日は決められません」（返ってくる）
営業:「そうですよね」（共感）＋ 空気をかき混ぜる ＋「こういう考え方なら、今日決められませんか」（投げ返す）
客 :「なるほど……でもやっぱり決められません」
営業:「分かりました。では、こういう考え方ならどうでしょう」
```

この構造を理解していない営業がほとんどである。1回投げて返ってきた時点で終わってしまう。理解できていれば、あとは**それぞれの返球のトークを作るだけ**の作業になる。

## 3. 反論は5パターンに収束する

商材を問わず、顧客が言うことは大きく次の5つに収束する。

1. ちょっと検討したい
2. 自分でも調べてみたい
3. 他社と比べたい
4. 誰かに相談したい
5. なんとなく踏ん切りがつかない

**それぞれに最低1本ずつスクリプトを持っておけば、的外れな返しにはならない。** 毎回同じ反論を受けているのに、その処理を一度も練習していない営業は多い。→ [sales-talk-script-practice](sales-talk-script-practice.md)

## 4. イエス・バット法 — 多くが誤用している

```
① 共感（Yes）を長くとる
② 空気をかき混ぜる
③「そういう考え方なら今日決めていただけませんか」と明確にボールを投げ返す
```

この3ステップのうち、①が短く③が抜けているのが典型的な誤用である。

- ✗「おっしゃることは分かるんですが、皆さんお忙しくて結局1週間経っても状況は変わらないんです。今日決めたほうがいいと思います」
  → 顧客は「決めたくない」と言ったのに、**その気持ちを一度も受け止めていない**。共感のない「バット」だけになり、対立で終わる
- ✗「私が良いと思うので」「あなたはお忙しいと思うので」
  → **忙しいかどうかを他人に決めてほしくないし、良いかどうかを売り手に言われても判断材料にならない**
- ○「今日、初めて聞いてすぐお決めになるのは大変ですよね」（共感を長く）→ 空気をかき混ぜる → 明確に投げ返す

## 5. 「検討します」の正体と切り返し

顧客は**検討したいのではなく「今この場で決められない」だけ**である。「検討します」はその場をしのぐ定型句として出ている。

実際、多くの顧客は検討する時間も判断基準も持っていない。高額のローンを1週間考えたところで、判断基準が増えるわけではない。

### 型（安心を先に渡してから空気をかき混ぜる）

1. **共感**「そうですよね。今日初めて聞いてすぐ決めるのは大変だと思います」
2. **安心を渡す**「ただ、これからする話を聞くと『検討してもしょうがないから今決めよう』と思っていただけるかもしれません。**その話を聞いてもやはり今日は決められないということなら、お持ち帰りいただいて構いません。** 少しだけ聞いていただけますか」
3. **空気をかき混ぜる**（生活を具体的に聞く）「お仕事は何時ごろ終わるんですか」「その後は何をされますか」「お休みになるのは何時ごろですか」
4. **想像させる**「その1週間の中で、この2つの選択肢を並べて考える時間は取れそうですか」「1週間後にお会いすると『結局考えられなかった』とおっしゃる方が本当に多いんです」
5. **投げ返す**「ですので、ある程度気に入っていただけている方には、この場でお決めいただいています。**改めて、そういう考え方なら今日決めていただけませんか**」

同じ構造を「相談したい」「比較したい」にも適用する。

## 6. 沈黙

「これでよろしいですか」と投げたら**黙る**。数秒ではなく、相手が口を開くまで待つ。

- 沈黙に耐えられなくなった顧客のほうが喋り出し、そこで本音が出る
- ただし出てくる質問の多くは**答えの決まっていること**（「途中で変更できますか」「持ち帰ってもいいんですよね」）。これは考えていないから何か喋っているだけなので、まともに取り合いすぎず、簡単に返してまた沈黙に戻す
- 「これって今日決めなくてもいいんですよね」→「**もちろん今日決めなくても大丈夫ですよ。何かどうしても今日決められない理由がおありですか**」→ また沈黙

沈黙は「待つ」という受け身の行為ではなく、姿勢・視線・手の置き方まで含めた能動的な演技である。

## 7. 空気をかき混ぜる

クロージングは、机を挟んで押し合う構図にしないほうが決まる。**横に並んで「まあやってみましょう」と背中を押す位置**に立つ。場が硬くなったら、軽い笑いや和やかな話題を一度挟んで温度を戻す。

## 8. 大事なことは相手に言わせる（第三者話法／ウィンザー効果）

営業本人が「このプランはあなたに向いています」と言っても「そう言うに決まっている」で終わる。**第三者を登場させる。**

- 「ご紹介くださった◯◯様は、これが△△様に合いそうだとおっしゃっていましたが、どう思われますか」
- 「同じような状況の方は、この仕組みを良いとおっしゃることが多いのですが、いかがですか」
- 「確かにその考え方なら今日決めてもいいかもしれない」——**この一言を顧客の口から出させる**のが狙い

## 9. 小さな「いいね」を積み上げる（一貫性の法則）

積み上げるのは「Yes」ではなく「**いいね**」である。**if を使って仮定させ、想像させる。**

- 「もしこれを始めたら、浮いたお金は何に使えそうですか」
- 「もしこの車を買われたら、最初にどこへ行きたいですか」
- 「**仮に**買うとしたら、支払いは3年と5年のどちらを選びそうですか」→「5年かな」
- 「内装はこちらとこちら、どちらが好みですか」
- → 「実はもう決めることはほとんど残っていないのですが、よろしければこのまま手続きに進みます」

**持ったことを想像させると、人は失いたくなくなる**（損失回避）。仮定の質問は、この心理を無理なく起動させる。

### 最上位から見せて削らせる

- 上位のプランを先に提示し、それが実現する状態を十分に想像してもらってから価格を見せる
- 「その額はきつい」→「では、この部分を減らしましょうか。ただしその場合はここが実現しなくなります」→ 顧客のほうから中間の条件を提案してくることが多い
- モデルルームや上位グレードの試乗車が同じ構造。**最上位を見せてから削る作業にすると、削りたくなくなる**

→ 削る交渉の具体は [sales-price-negotiation](sales-price-negotiation.md)

## 10. 心理の実像 — 顧客は振り子のように揺れているだけ

商談の最後まで来た顧客は、「このサービスがあったほうが良いか、ないほうが良いか」では**迷っていない**（迷っているならもっと手前で断っている）。

迷っているのは「これにこの金額を払う価値があるのか」「今決めていいのか」であり、良い/悪いの判断ではなく**振り子が揺れているだけ**である。やることは、その振り子を「いい」側に軽く弾くこと。ここまで来ていれば難しくない。

### マインドセット

> **お客様はもうこのサービスを欲しくなっていて、あとは自分が背中を押すのを待っている——と思い込んでやる。**

この思い込みがないと、最後のひと押しの言葉が小さくなり、顧客は「この営業も自信がないのだな」と受け取る。

## 前提となる見た目・話し方

「どんな人が、どんな風に喋るか」で勝負がついている、という構図はクロージングでも変わらない。使うべきなのは「**見た目はコントロールできる／どんな人物かは自己開示でコントロールできる**」という実務的な部分である。→ [sales-first-impression](sales-first-impression.md)
