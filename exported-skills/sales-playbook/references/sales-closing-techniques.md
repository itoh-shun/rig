# クロージングと反論処理

クロージングとは「**白黒をつける**」こと、そして「**最後の背中を押す**」こと。

重要な前提: **クロージングは前工程が終わっている前提の技術**。不満の顕在化 → 解決策の提示 → 小さな階段を登らせる、をやらずに「これでよろしいでしょうか」と言えば「え、急に何？」になる。それどころか、そこまで到達できているかどうか自分で分かっていない営業も多い。→ [sales-discovery-questioning](sales-discovery-questioning.md)

## 1. 終わり方（ゴール）を先に決める

商談の終わり方を、良い順に定義していない営業は方向を出せない。語り手の前職での型は**この4つしかない**:

1. 申し込み
2. **お断り**（白黒をつけた）
3. 相手に宿題を渡し、次回＝申し込みのアポイントを取る
4. 相手に宿題を渡し、次回＝審査と申し込みがセットのアポイントを取る（保険なら健診など）

> 「ちょっと検討して、こちらからご連絡します」は**この4つのどれでもない**＝終わり方になっていない。

「4つの終わり方は何？」と聞いて答えられない営業は、まずここから。

## 2. クロージングはキャッチボールである

```
営業:「これで進めませんか」（ボールを投げる）
客 :「今日は決められません」（返ってくる）
営業:「そうですよね」（共感）＋ 空気をかき混ぜる ＋「こんな考え方だったら今日決められませんか」（投げ返す）
客 :「なるほど…でもやっぱり決められません」
営業:「分かりました。じゃあこんな考え方だったら決められませんか」
```

このキャッチボールの構造を理解していない営業がほとんど。理解できれば、あとは**それぞれの返球のトークを作るだけ**。

## 3. 反論は5パターンしかない

商材を問わず、顧客が言うことは大きく次の5つに収束する。

1. ちょっと検討したい
2. 自分でも研究・勉強してみたい
3. 他社と比べたい
4. 誰かに相談したい
5. なんとなく踏ん切りがつかない

**それぞれに最低1本ずつスクリプトを持っておけば、的外れな返しにはならない**。毎回「親に相談したい」と言われているのに、その反対処理を練習していない営業は多い。→ [sales-talk-script-practice](sales-talk-script-practice.md)

## 4. イエス・バット法 — 9割が誤用している

```
① 共感（Yes）を長くとる
② 空気をかき混ぜる
③「そんな考え方だったら今日決めてもらえませんか」と明確にボールを投げ返す
```

この3ステップのうち、①が短く③が抜けているのが典型的な誤用。

- ✗「おっしゃることは分かるんですけど、皆さん忙しくてお決めになれないので、結局1週間経っても分からないままなんです。今日決めたほうがいいと思います」
  → 顧客は「決めたくない」と言ったのに、**その決めたくない気持ちを Yes していない**。単なる「バット砲」で喧嘩別れになる。
- ✗「私が良いと思うので」「あなたは忙しいと思うので」
  → **忙しいかどうかを他人に決めてほしくないし、良いかどうかを営業に言われても意味がない**。大きなお世話。
- ○「今日、初めて聞いてすぐお決めになるのは大変ですよね」（共感を長く）→ 空気をかき混ぜる → 明確に投げ返す

## 5. 「検討します」の正体と切り返し

顧客は**検討したいのではなく「今決められない」だけ**。「検討します」と言ってしまっただけ。

実際、多くの顧客には検討する時間も判断基準もない。500万の車のローンを1週間考えて「払えるぜ」になるわけではない。

### 型（安心を先に渡してから空気をかき混ぜる）

1. **共感**「そりゃそうですよね。今日初めて聞いてすぐ決めるのは大変じゃないですか」
2. **安心を渡す**「ただ、今から私がする話を聞くと『検討してもしょうがないから今決めようかな』と思っていただけるかもしれません。**その話を聞いても、やっぱり今日は決められないということなら、全然お持ち帰りいただいて大丈夫です**。ちょっとその話を聞いていただけますか？」
3. **空気をかき混ぜる**（生活を具体的に聞く）「お仕事は何時ごろ終わるんですか」「その後は？家でビールとか？」「シャワーを浴びて何時ごろお休みに？」「朝は何時？」
4. **想像させる**「その中で、2万円にしようか3万円にしようか、徹夜で考えていただけそうですか」「1週間後にお会いすると『一切考えられなかった』とおっしゃる方が本当に多いんです」「1日3〜4時間、私のために検討していただけそうですか」
5. **投げ返す**「なので、今ある程度気に入っていただいている方には、この場でお決めいただいています。**改めて、そんな考え方だったら今日決めてもらえませんか**」

同じ構造を「相談したい」「比較したい」にも適用する。

## 6. 沈黙

「これでよろしいですか」と投げたら**黙る**。数十秒ではなく**数分**。

- 沈黙に耐えられなくなった顧客のほうが喋り出し、そこで本音が出る
- ただし出てくる質問の多くは**答えが決まっていること**（「途中で増やせるんですか」「持ち帰っていいんですか」）。これは考えていないから何か喋っているだけ。まともに取り合いすぎず、簡単に返してまた沈黙に戻す
- 「これって今日決めなくてもいいんですよね？」→「**もちろん今日決めなくても大丈夫ですよ。何かどうしても今日決められない理由がありますか？**」→ また沈黙

紅茶を飲む、腕を組む、視線を送る——沈黙は演技を伴う。

## 7. 空気をかき混ぜる

クロージングは対面で押し合う構図にしないほうが決まる。**横に座って「まあやろうよ」と背中を押す存在**になる。緊迫して場が硬くなったら、くすっとした笑いや和やかな話題を挟む。

## 8. 大事なことは相手に言わせる（第三者話法／ウィンザー効果）

営業本人が「このプランはあなたに向いています」と言っても「そりゃそう言うだろう」で終わる。**第三者を登場させる**。

- 「ご紹介いただいた◯◯様は、これが△△様にぴったりだとおっしゃっていたんですが、どう思われますか？」
- 「あなたのように年収の高い方は、皆さんこの仕組みを良いとおっしゃるんですが、いかがですか？」
- 「確かにそういう考え方だったら今日決めてもいいかも」——**この一言を顧客の口から出させる**のが狙い

## 9. 小さな「いいね」を積み上げる（一貫性の法則）

積み上げるのは「Yes」ではなく「**いいね**」。**if を使って仮定させ、想像させる**。

- 「もしこのサービスを始めたら、そのお金は何に使えますか？」
- 「もしこの車を買っていただいたら、最初にどこへ行きたいですか？」
- 「**仮に**買うとしたら、ローンは3年と5年どちらを選びそうですか？」→「5年かな」
- 「シートは白い革張りと黒、どちらがいけてます？」「この車を買われる方は基本このホイールのオプションを付けますが、もし買うならどちらが？」
- → 「実はもう決めることはほとんど残っていないんですが、よろしければこのまま手続きを進めます」

**持ったことを想像させると、人は失いたくなくなる**（損失回避）。

### 最高のものから見せて削らせる

- 保険なら年収の10〜15%の高いプラン（月10万など）を先に提示し、「これなら3000〜4000万貯まります、老後ハワイに行けますね」と散々想像させてから値段を見せる
- 「10万はきつい」→「では**ハワイを半分にしましょうか**。2年に1回しか行けませんが大丈夫ですか？」→ 顧客のほうから「7万5000円ならどうなる？」と間を攻めてくる
- マンションのモデルルームが同じ構造（ビルトインTV・床暖・キッチンが全部オプションで3000万）。**最高を見せてから削る作業にすると、削りたくなくなる**

## 10. 心理の実像 — 顧客は振り子のように揺れているだけ

商談の最後まで来た顧客は、「このサービスがあったほうが幸せか、ないほうが幸せか」では**迷っていない**（迷っているならもっと手前で断っている）。

迷っているのは「これに5万円払う価値があるのか」「今決めていいのか」であり、良い/悪いの判断ではなく**振り子が揺れているだけ**。やることは、その振り子を「いい」側にポンと弾くこと。ここまで来ていれば難しくない。

### マインドセット

> **お客様はもうこのサービスを欲しくなっていて、あとは私が背中を押すのを待っている——と思い込んでやる。**

## 効果（語り手の実績・n=1）

営業所長として新人に同行していた時期、**同行商談の成約率90%超、しかもほぼ全件即決**。使っていたのは「ゴールを決める・沈黙・空気をかき混ぜる・第三者話法で大事なことを言わせる」の4つ。

## 前提となる見た目・話し方

「どんな人が、どんな風に喋るか」で勝負がついている、という主張はクロージングでも同じ。ただし語り手が根拠に引くメラビアンの法則の扱いには注意が必要（→ [sales-first-impression](sales-first-impression.md) の注記を参照）。使うべきなのは「**見た目はコントロールできる／どんな人かは自己開示でコントロールできる**」という実務的な部分。
