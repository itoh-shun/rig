# トークスクリプトと練習（再現性の作り方）

このチャンネルの営業論の**背骨**にあたる考え方。「営業は科学であり、再現可能な技術である」という主張の実装がここにある。

> **営業は舞台に立った俳優と同じ。台本を覚えていない俳優はいない。**

## 台本がない組織で起きること

- **稀なセンスを持つ人だけが生き残る組織**になる
- 台本があれば、センスのある人はさらに売れ、そうでない人も生き残れる

## 台本が効く3つの理由

1. **認知資源が空く** — 丸暗記して演じきれるまで覚えると、「何を喋るか」に脳を使わずに済む。空いた分を**顧客の表情・心理の観察**に使え、「この人は今こういう心理状態だから、台本のここから喋ろう」と選べるようになる
2. **共通言語ができる** — 先輩・後輩のアドバイスが噛み合う。失敗の体験を共有して貯められる。若手が育ちやすい
3. **教えられる** — 共通言語があるので上司から部下へのトレーニングが成立し、成長が速い

## 営業マニュアルと台本は別物

| | 中身 |
|---|---|
| 営業マニュアル | 「こういう理由でこういうスタイルで営業しよう」「自社商品はこういうものだからここは必ず説明しよう」 |
| **台本（スクリプト）** | 「初めましてから、このトークで、こう喋る」という**逐語の台本** |

両方大事だが、**優先は台本**。語り手は前職（生保）でマニュアルを読んだことがなく、台本で育っている。

> 金融機関だったので「日経新聞を読め」「経済を勉強しろ」という指導が周囲には多かったが、語り手の部署では「**日経新聞を読んでいる暇があったら台本を覚えてロープレしなさい**」と教えていた。経済の勉強は台本を演じきれるようになってからで遅くない。

## アドリブは禁止 — アイドリングトークまで台本にする

商談の構造は「初めまして → アイドリングタイム → 本編 → クロージング」。この**アイドリング（導入）も台本**であり、アドリブはない。

- アイドリングは「本編に気持ちよく入るための助走」。**毎回同じ型でいい**ほうが、いい入りが再現できる
- ここでアドリブを入れると、相手の反応次第で入りが崩れる
- 何個も要らない。**1個で十分**

## 雑談をするな

アイスブレイクの雑談は、やらないほうがいい。理由は4つ。

1. **練習していないことを本番でやるから** — 「初めまして、お時間いただきありがとうございます」から先は全部練習した台本を出すのに、雑談だけ練習していない。センスのない人がやるとリスクにしかならない
2. **自信のない営業ほど雑談する** — 本題を切り出す勇気がなくて雑談で引き延ばす。時間単価の高い顧客からは「アポを取っておいて、なぜどうでもいい話をしているんだ」と見える。切り出すころには「この営業は能力が低い」と判断が終わっている
3. **顧客は仲良くなりたいと思っていない** — 「初対面の営業と仲良くなってから話を聞きたい」という顧客と「仲良くなってから切り出したい」という営業の間には深い谷がある。共通点探しも同じ（→ [sales-first-impression](sales-first-impression.md)）
4. **盛り上がりは購買と無関係** — 盛り上がっても役に立たなければ買わないし、盛り下がっていても役に立つと思えば買う。「めちゃくちゃ面白いのに全然売れない営業」はどこにでもいる

### 代わりに言うこと

> 「お客様は営業の話を聞くためにお時間をくださっているので、**早速本題に入らせていただきます**。本題が終わった後で私と雑談したければ、私は時間がございます」

磨くべきは雑談力ではなく**商談力**——自社のサービスが顧客の人生に本当に役立つかを**想像させるスキル**。→ [sales-discovery-questioning](sales-discovery-questioning.md)

## 台本に落とすべき場面

| 場面 | 本数の目安 |
|---|---|
| アイドリング（導入） | 1本 |
| 不満・不安の顕在化（自社が解決できる課題ごと） | 課題の数だけ |
| 反論処理（検討したい／研究したい／比較したい／相談したい／踏ん切りがつかない） | **5パターン各1本以上** → [sales-closing-techniques](sales-closing-techniques.md) |
| クロージング | 終わり方4種に対応 |
| 紹介依頼 | → [sales-referral-generation](sales-referral-generation.md)（ここのロープレをしている組織はほぼない） |
| 受付突破（リストの種類ごと） | → [sales-prospecting-cold-calling](sales-prospecting-cold-calling.md) |

前職では**2時間半の商談トークを丸ごと暗記**し、ボールペンを出す角度まで練習していた。反論処理は場面ごとのパターンをファイル化して蓄積していた。

## 台本は「覚えたら終わり」ではない — 演技が要る

> スクリプトがあって、**そこにどういう表情で演じるかが演技**。ロールプレイは演技レッスン。

台本が「作ってあるのに使われていない」組織も多い。

## 新人が最初の半年でやること（3つ）

1. **始業1時間前に出社する** — 身だしなみは家で整えて出る。1時間で、ロープレ、口を回す練習、トークスクリプトの音読、心と道具の準備。これを半年続けられるか
2. **会社から与えられた KPI を必ず達成する** — 「月4アポ」を毎月入れ切れば1年後には結果が出ている。多くの人は達成しないまま半年過ごす。金曜までに翌週のアポが1件も入っていないなら土日は休まない
3. **仕事の夢を見るまで考える** — アポが取れていない状態で月曜を迎える夢を見て飛び起きる、くらい考え続ける

> 語り手自身の新人期は「夜中3〜4時までロープレ、6時に起きてロープレ」。生保は業務後の商談が多く、帰宅が23時、翌日の資料を作って0時半、そこからロープレ、力尽きて2〜3時に寝て、朝もう一度ロープレ。

### やらないほうがいいこと

- **結果も出ていないうちにプライベートや権利を主張すること**。新人のうちは他のメンバーの稼ぎから給料をもらっている
- ただし「全て犠牲にして頑張ったが今月はダメでした」と悔し涙を流せるならそれでいい

> （注）このセクションは長時間労働を前提にした精神論を含む。**労務管理上そのまま適用できない環境が多い**。使うなら「準備時間を確保する」「KPI を必達に置く」という構造だけを取り、時間の使い方は各社の労務基準に合わせて翻訳すること。

## デジタル化との接続（対談ダイジェストより）

台本主義はツールと相性が良い。商談支援プラットフォームの開発者との対談で挙がった論点:

- **商談の録音・ログが「意味のある録音」になってきた** — どういう会話をしたからこの結果になったのか、が数値化・可視化されつつある。商談のボトルネックが見えるようになる
- **1つの商談をチームで共有できる** — 課題の共有、**トレーニングニーズの発見**、正しいプロセスの確定がしやすくなる
- **スクリプトの「仮説の答え合わせ」ができる** — どんな仮説で作った台本なのかを、実データで検証できる
- **AI に置き換わらない部分**: 「営業パーソンは**情報源としての立ち振る舞いをするのではなく、価値を提供する**側に立つことが必須になる」

## 向き不向きの判断を早まらない

学生時代に否定された経験がない人ほど、断られ続けて「向いていない」と早期に判断する。**入社3〜4ヶ月は部活で言えば4〜5日目**。1〜2年やらないと向き不向きは分からない。→ [sales-mindset-antipatterns](sales-mindset-antipatterns.md)
