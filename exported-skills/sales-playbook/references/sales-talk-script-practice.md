# トークスクリプトと練習（再現性の作り方）

このプレイブック全体の**背骨**にあたる考え方。「営業は再現可能な技術である」という立場の実装がここにある。

> **営業は舞台に立つ俳優と同じ。台本を覚えていない俳優はいない。**

## 台本がない組織で起きること

- **稀なセンスを持つ人だけが生き残る組織**になる
- 台本があれば、センスのある人はさらに売れ、そうでない人も生き残れる

台本は優秀な人の足枷ではなく、**優秀でない人の下限を引き上げる仕組み**である。この理解がないと「うちの優秀な営業は台本など要らない」で議論が止まる。

## 台本が効く3つの理由

1. **認知資源が空く** — 演じきれるまで覚えると、「何を喋るか」に脳を使わずに済む。空いた分を**顧客の表情・心理の観察**に使え、「この人は今こういう状態だから、台本のここから話そう」と選べるようになる
2. **共通言語ができる** — 先輩・後輩のアドバイスが噛み合う。失敗の経験を共有して蓄積できる。若手が育ちやすい
3. **教えられる** — 共通言語があるので上司から部下へのトレーニングが成立し、立ち上がりが速くなる

## 営業マニュアルと台本は別物

| | 中身 |
|---|---|
| 営業マニュアル | 「こういう理由でこういうスタイルで営業する」「自社商品はこういうものだからここは必ず説明する」 |
| **台本（スクリプト）** | 「初めましてから、このトークで、こう喋る」という**逐語の台本** |

両方大事だが、**新人にとっての優先順位は台本**である。業界知識や周辺の勉強は、台本を演じきれるようになってからでも遅くない。順序を逆にすると、知識はあるのに商談が組み立てられない状態が長く続く。

## アドリブは禁止 — 導入まで台本にする

商談の構造は「初めまして → 導入（アイドリング） → 本編 → クロージング」。この**導入も台本**であり、アドリブはない。

- 導入は「本編に気持ちよく入るための助走」。**毎回同じ型でいい**ほうが、良い入り方が再現できる
- ここでアドリブを入れると、相手の反応次第で入りが崩れる
- 何種類も要らない。**1本で十分**

## 雑談をするな

アイスブレイクの雑談は、やらないほうがいい。理由は4つある。

1. **練習していないことを本番でやることになる** — 「初めまして、お時間をいただきありがとうございます」から先は練習した台本を出すのに、雑談だけ練習していない。訓練していない領域はリスクにしかならない
2. **自信のない営業ほど雑談する** — 本題を切り出す勇気がなくて雑談で引き延ばす。時間単価の高い顧客からは「アポを取っておいて、なぜ関係のない話をしているのか」と見える。切り出す頃には評価が終わっている
3. **顧客は仲良くなりたいと思っていない** — 「初対面の営業と打ち解けてから話を聞きたい」という顧客と「打ち解けてから切り出したい」という営業の間には深い谷がある。共通点探しも同じ（→ [sales-first-impression](sales-first-impression.md)）
4. **場の盛り上がりは購買と無関係** — 盛り上がっても役に立たなければ買わないし、盛り下がっていても役に立つと思えば買う。「話は面白いのに売れない営業」はどこにでもいる

### 代わりに言うこと

> 「お客様は営業の話を聞くためにお時間をくださっているので、**さっそく本題に入らせていただきます**。本題が終わった後で雑談をご希望でしたら、私は時間がございます」

磨くべきは雑談力ではなく**商談力**——自社のサービスが顧客の状況にどう効くかを**想像させるスキル**である。→ [sales-discovery-questioning](sales-discovery-questioning.md)

## 台本に落とすべき場面

| 場面 | 本数の目安 |
|---|---|
| 導入（アイドリング） | 1本 |
| 不満・不安の顕在化（自社が解決できる課題ごと） | 課題の数だけ |
| 反論処理（検討したい／調べたい／比較したい／相談したい／踏ん切りがつかない） | **5パターン各1本以上** → [sales-closing-techniques](sales-closing-techniques.md) |
| クロージング | 終わり方4種に対応 |
| 紹介依頼 | → [sales-referral-generation](sales-referral-generation.md)（ここを練習している組織はほぼない） |
| 受付突破（リストの種類ごと） | → [sales-prospecting-cold-calling](sales-prospecting-cold-calling.md) |

長い商談をまるごと暗記し、資料を出す手順や道具を置く位置まで固定している組織もある。そこまで固めると、当日の変数が顧客の反応だけになる。反論処理は場面ごとにファイル化して蓄積していく。

## 台本は「覚えたら終わり」ではない — 演技が要る

> スクリプトがあって、**そこにどういう表情と間で演じるかが演技**。ロールプレイは演技のレッスンである。

台本が「作ってあるのに使われていない」組織は多い。原因はたいてい、配って終わりにしていて、演じる訓練の場がないことにある。台本の配布と練習の場はセットで用意する。

## 新人が最初の期間にやること（3つ）

1. **練習の時間を毎日固定で確保する** — ロープレ、発声、スクリプトの音読、道具の準備。時間帯は組織の労務ルールの中で決める。重要なのは長さではなく、**毎日同じ時間に必ずある**こと
2. **与えられた KPI を必ず達成する** — 「月◯アポ」を毎月入れ切れば、期間が経過した時点で結果が出ている。多くの人は未達のまま期間を過ごす。週の後半になっても翌週のアポが埋まっていないなら、そこが最優先タスクになる
3. **考える時間を確保する** — 移動中や商談後の10分でよいので、次の商談の組み立てを毎日考える

> （注）新人育成では長時間労働が精神論として語られやすい。**構造（練習時間を確保する／KPI を必達に置く／短期で振り返る）だけを取り、時間の使い方は各組織の労務基準に合わせて設計すること。** 練習を業務時間外に押し出す設計は、定着率を下げるうえに法的にも成立しない。

## デジタル化との接続

台本主義は記録ツールと相性が良い。

- **商談の録音・ログが分析可能になった** — どういう会話をしたからこの結果になったのか、を後から検証できる。商談のボトルネックが特定できるようになる
- **1つの商談をチームで共有できる** — 課題の共有、**トレーニングニーズの発見**、正しいプロセスの確定がしやすくなる
- **スクリプトの「仮説の答え合わせ」ができる** — どんな仮説で作った台本なのかを、実データで検証できる。台本は作って終わりではなく、改訂され続けるべきものである
- **人が担う部分が変わる** — 情報を伝えるだけの役割は代替されやすい。営業は**情報源としてではなく、判断を助ける側**に立つ必要がある

記録を取る際は、顧客への録音の同意など、法令とプライバシーの取り扱いを先に整える。

## 向き不向きの判断を早まらない

学生時代に否定された経験が少ない人ほど、断られ続けて「向いていない」と早期に判断しやすい。**入社から数ヶ月は、技能の習得としてはまだ導入部にすぎない。** 一定期間やらないと向き不向きは判断できない。→ [sales-mindset-antipatterns](sales-mindset-antipatterns.md)
