# 商談後フォロー（つなぎの3手）

> **単一動画からの蒸留（n=1）。** 裏取りが薄い点、および手法が日本の商習慣・時代性に強く依存する点に注意。

初回訪問が終わり、次回のアポイント（プレゼンなど）を取れた**あいだの期間**に何をするか。ここを型として持たせると成約率が上がる、という主張。

## 1. メッセージアプリで繋がり、当日中にお礼を送る

- その場で**メッセージアプリを交換**（若い層は SNS の DM になっている場合もある）
- お礼のメッセージと**次回の日程**を送る
- さらに一歩進めるなら「今日はありがとうございました、次回楽しみにしております」を**動画メッセージ**で送る

## 2. 翌日に手書きの手紙が着くようにする（時代に逆行する手）

デジタルで繋がった直後に、あえて紙を届ける。

| 要素 | 指定 |
|---|---|
| 媒体 | 和風の便箋（はがきは次善） |
| 筆記具 | **ボールペンは使わない**。水性の万年筆か筆ペン |
| 文字 | **必ず手書き** |
| 送り方 | **速達** |
| 切手 | 記念切手やキャラクター切手（速達用には記念切手がないので、封筒用・はがき用で使う） |
| 仕上げ | 落款のような**角印**を用意して押す。封の綴じ目に押すのも良い |

> 語り手は「夢」の印と「オカポン」の印の2種類を用意し、使い分けていた。

狙いは細部の演出そのものではなく、**細部に気づく層をふるいにかけること**。

> 仕事ができる人ほどこうした小さなところに気づくので、きちんとやっていると「いけてる人」が顧客になっている確率が上がる。

## 3. 紹介元にお礼の連絡をする（紹介案件のみ）

紹介経由の商談なら、**紹介元にも必ず報告**する。

これをやると紹介元から被紹介者へ「次の話を聞くらしいじゃないか、良かっただろう、お前も買ったほうがいいよ」という**後押しが入る可能性**がある。報告はマナーであると同時に、その期待値込みの一手。→ [sales-referral-generation](sales-referral-generation.md)

## 適用時の注意

- 手紙・切手・角印は日本の商習慣に依存する。B2B SaaS や海外顧客ではそのまま機能しない
- 「速達で翌日に届く」前提は郵便事情の変化で崩れうる **※要確認**
- 本質は「**デジタルで即座に、アナログで丁寧に、二重に接触する**」「**紹介元を情報の輪から外さない**」の2点。手段はこれを満たす形に置き換えてよい
