# 営業プレイブック

B2C・高額商材（保険・投資不動産・住宅・車など）の対面営業を対象とした実務知識。**「営業は再現可能な技術である」という立場**で書かれている。

## 使い方

相談の内容に応じて `references/` の該当ページを読む。**全部を読み込まない**——1つの相談は通常1〜3ページで足りる。

| 相談の内容 | 読むページ |
|---|---|
| 紹介が出ない／リファラルを増やしたい | `references/sales-referral-generation.md` |
| アポが取れない／見込み客がいない | `references/sales-prospecting-cold-calling.md` |
| 第一印象・自己紹介・商談場所 | `references/sales-first-impression.md` |
| ヒアリングが浅い／なぜ買うのか分からない | `references/sales-discovery-questioning.md` |
| 「検討します」で終わる／決めきれない | `references/sales-closing-techniques.md` |
| 値下げを求められた | `references/sales-price-negotiation.md` |
| トークが属人化している／新人が育たない | `references/sales-talk-script-practice.md` |
| 商談と商談のあいだに何をするか | `references/sales-followup-retention.md` |
| メンタルが折れる／向いていない気がする | `references/sales-mindset-antipatterns.md` |

各ページは相互にリンクしている。リンク先が必要になったときだけ辿る。

## この知識体系の背骨（これだけは先に知っておく）

1. **人は不満・不安がなければ買わない。** 買い物は不満を解決する行動の一つ。しかも顧客は自分の不満を言語化していないし優先順位もつけていない。それを直視させ、腹に落とすのが営業の最重要の仕事。
2. **営業は舞台に立った俳優と同じ。台本を覚えていない俳優はいない。** アドリブを許すと「稀なセンスを持つ人だけが生き残る組織」になる。
3. **紹介は「紹介したい」から出るのではなく、「紹介すると自分が感謝される」から出る。** 矢印の向きを間違えると紹介は永久に出ない。
4. **白黒をつける。** 断られてもいない・契約にもなっていない商談の滞留が、売れない営業の最大の特徴。
5. **クロージングは前工程が終わっている前提の技術。** そこまで到達していないのに背中を押しても意味がない。

## 使うときの注意（重要）

この知識は**一人の実務家の経験談を蒸留したもの**であり、統制された研究ではない。

- **`※要確認` と書かれた箇所**は、根拠が単一の証言のみ、または出典が特定できていない主張。断定して引用しない。
- **`status: draft` 相当のページ**（`sales-price-negotiation` / `sales-followup-retention`）は単一の動画のみを根拠とする。冒頭に注意書きがある。
- **数値（成約率・アポ率・年収など）はすべて個人または個別支援先の実績値**。業界・商材で大きく変わる。
- **メラビアンの法則への言及がある**が、これは原典が限定的な実験であり、営業トーク全般への一般化は広く知られた誤用。`sales-first-impression.md` に注記があるので、その数値を根拠として使わないこと。
- **長時間労働を前提にした精神論を含む**箇所がある（新人の過ごし方など）。労務環境によってはそのまま適用できない。構造だけを取り、時間の使い方は各組織の基準に翻訳すること。
- **日本の商習慣に強く依存する**手法がある（手書きの手紙、商談場所の選び方など）。B2B SaaS や海外顧客にはそのまま適用できない。

助言するときは、この知識を**そのまま指示として渡さず**、相手の商材・チャネル・組織の前提に翻訳してから使う。
