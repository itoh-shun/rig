クロージングは「決めさせる技術」ではなく、**白黒をつける技術**である。申し込みを取ることと同じくらい、断りを取ることもクロージングの成功に数える。宙ぶらりんのまま終わった商談だけが失敗。

## 前提 — クロージングは前工程の結果でしかない

課題の顕在化と解決策の合意が済んでいない状態で「いかがでしょうか」と言えば、相手には唐突にしか聞こえない。クロージングのトークを増やす前に、自分が前工程のどこまで到達したのか記録から言えるかを確かめる。→ [[sales-discovery-questioning]]

**多くの「クロージングが弱い」は、クロージングの問題ではなく到達点の把握の問題**。商談記録を読んで「相手はどの課題に、どれくらい困っていると言ったか」が再構成できないなら、そこが原因。

## 終わり方を先に定義する

商談を始める前に、許容できる終わり方を良い順に並べておく。並べていない営業は場を方向づけられない。汎用的にはこの4つで足りる。

1. **合意・申し込み**
2. **断り**（相手の意思が確定した）
3. **宿題を渡し、次回を「決める場」として日時で押さえる**
4. **宿題を渡し、次回を「決める場＋必要な手続き」として日時で押さえる**（審査・稟議・実物確認などが挟まる商材）

「検討して、こちらからご連絡します」は**このどれでもない**。連絡が来ない前提の終わり方であり、実質は保留＝失敗に分類する。

## 反論処理はキャッチボールの構造で見る

```
営業  これで進めませんか            ← 投げる
顧客  今日は決められません          ← 返ってくる
営業  そうですよね（共感を長く）
      + 場をほぐす
      + こういう考え方でも決められませんか  ← 投げ返す
顧客  なるほど、でもやっぱり…
営業  分かりました。ではこの考え方ではどうでしょう ← また投げ返す
```

この構造が見えていれば、あとは**返球ごとのトークを用意するだけの作業**になる。→ [[sales-talk-script-practice]]

### 反論の収束先

商材が変わっても、断り文句は実務上ほぼこの5つに収束する。

1. 検討したい
2. 自分でも調べたい
3. 他社と比べたい
4. 誰かに相談したい
5. 理由はないが踏ん切りがつかない

**それぞれに最低1本ずつ返球を用意しておく**。毎回同じ断り文句を受けているのに、その返球だけ練習していない、という状態が一番多い。

## Yes-But は3ステップで、①と③が落ちやすい

```
① 相手の気持ちに共感する（長く取る）
② 場をほぐす／視点を変える材料を出す
③ 「その考え方なら今日決められませんか」と明確に投げ返す
```

典型的な失敗は①が一言で終わり、③が無いまま説得に入ること。

- ✗「おっしゃることは分かるのですが、皆さんお忙しくて結局1週間経っても変わらないんです。今日決めたほうがいいですよ」
  → 相手は「決めたくない」と言ったのに、その気持ちを受け止めていない。**共感の形をした反論**にしかなっていない。
- ✗「私が良いと思うので」「お忙しいと思うので」
  → 良し悪しも忙しさも、相手が決めること。営業が代わりに決めた瞬間に反発が立つ。
- ○「今日初めて聞いて、その場で決めるのは大変ですよね」と受け切ってから、②③へ進む。

## 「検討します」の扱い

「検討します」は**検討したいという意思ではなく、今決められないという状態の言い換え**であることが多い。実際に検討するための時間も判断基準も持っていない相手に「では1週間後に」と言えば、1週間後も同じ状態で会うことになる。

型としては、**先に安心を渡してから、検討という行為を具体的に想像させる**。

1. **共感** —「今日初めて聞いて、その場で決めるのは大変ですよね」
2. **安心を渡す** —「この後の話を聞いても、やはり今日は決められないということでしたら、持ち帰っていただいて構いません。少しだけ聞いていただけますか」
3. **具体を聞く** — 相手の1日の使い方を聞く（仕事の終わり、帰宅後、就寝、翌朝）
4. **想像させる** —「そのなかで、この件を考える時間はどれくらい取れそうですか」
5. **投げ返す** —「なので、ある程度良いと思っていただけている方には、この場で決めていただいています。改めて、いかがでしょうか」

同じ構造が「相談したい」「比較したい」にも使える。**変えるのは③で聞く具体だけ**（相談なら相手が誰で何を判断するのか、比較なら何と何をどの基準で比べるのか）。

> ここでの線引き：**相手が持ち帰る権利を実際に残しておくこと**。2で「持ち帰って構わない」と言いながら実際には帰さないなら、それは安心を渡したのではなく嘘をついたことになる。

## 沈黙

投げたら黙る。数十秒ではなく、耐えられなくなるまで。

- 先に喋り出すのはたいてい相手で、そこで本音が出る
- ただし出てくる質問の多くは**答えが決まっていること**（「後から変更できますか」「持ち帰ってもいいですか」）。まだ考えていないから何か喋っているだけなので、短く答えて沈黙に戻す
- 「今日決めなくてもいいんですよね」→「もちろん構いません。何か、今日決められない理由がありますか」→ また黙る

沈黙は不機嫌とセットにすると圧力になる。**穏やかなまま黙る**（飲み物に手を伸ばす、視線を外す）ことで、圧ではなく間になる。

## 場の作り方

対面で押し合う構図にすると、相手は防御に入る。**同じ側に座って一緒に見る**構図に寄せる。場が硬くなったら、軽い話題や笑いを挟んでから戻す。

## 大事な判断は相手の口から出す

営業本人が「これはあなたに合っています」と言っても「そう言うだろう」で終わる。第三者や相手自身の言葉に置き換える。

- 「ご紹介いただいた◯◯様は、これが△△様に合いそうだとおっしゃっていましたが、どう思われますか」
- 「同じ状況の方はこの点を評価されることが多いのですが、いかがですか」
- 狙いは「確かに、その考え方なら決めてもいいかもしれない」を**相手に言わせる**こと

引用する第三者は実在で、実際にそう言った人に限る。作った第三者を挟むのは、効く分だけ嘘としても効く。

## 小さな合意を積み上げる

積み上げるのは「はい」ではなく「いいですね」。**仮定形で想像させる**。

- 「仮に始めるとしたら、まず何から使いますか」
- 「もし導入するなら、期間は3年と5年のどちらが合いそうですか」
- 「この構成を選ばれる方が多いのですが、もし選ぶならどちらですか」
- → 「実は決めることはほとんど残っていないのですが、このまま進めてよろしいですか」

**持った状態を想像した後は、失うほうが痛くなる**（損失回避）。

### 上から削る

上位構成を先に見せて価値を十分に想像させてから、価格を出して削っていく。削る作業になると、削りたくなくなる。

- 上位案で得られる状態を具体的に描かせる → 価格を出す → 「では、この部分を落としますか。その場合ここができなくなりますが、大丈夫ですか」
- 相手のほうから「この中間はいくらですか」と聞いてくれば、主導権は相手に渡ったまま前に進んでいる

→ 価格そのものの交渉は [[sales-price-negotiation]]

## 最後まで来た相手が迷っていること

商談の最後まで残った相手は、「これがあったほうがいいか」では迷っていない（迷っていればもっと手前で断っている）。迷っているのは**支払う額に見合うか／今決めていいか**であって、良し悪しの判断ではない。振れているものを片側に寄せるだけ、と考えると力みが取れる。

そのうえで前提にする姿勢は「相手はもう欲しくなっていて、あとは押されるのを待っている」。※要確認 — この構えが成約率に効くという主張は体験談ベースで、対照実験があるわけではない。効くのは自信のなさが声と間に出るのを防ぐ範囲まで、と見ておく。

## 使ってはいけない場面

クロージングの技術は**相手の判断を助ける**ためのもので、判断能力の不足に付け込むためのものではない。次のいずれかに当たるなら、その場で決めさせない。

- 相手が商材の**不利な条件を理解していない**（解約条件・総支払額・更新後の価格）
- 相手に**決裁権がない**のに、その場で押し切ろうとしている
- 判断力が落ちている状態（深夜、体調不良、強い動揺）
- 沈黙・時間の圧・第三者話法を、**事実でない前提**の上で使っている

この線を越えた成約は、解約・クレーム・紹介の断絶として後で戻ってくる。→ [[sales-followup-retention]]

## 前提となる立ち居振る舞い

「何を言うか」より「誰がどう言うか」が効く、という主張はクロージングでも同じ。ただしその根拠として引かれがちな数値には注意が必要（→ [[sales-first-impression]] の注記）。実務として使えるのは「**見た目は準備でコントロールできる／どういう人間かは自己開示でコントロールできる**」という部分だけ。
