# 「人間らしさ」の定義を組み直す

> **MDE 測定後の注記（2026-07-31）**:
> この文書の「表層は完全にゼロ」「余剰仮説は外れた」などの断定は強すぎた。
> held-out 人間記事による陽性対照では、31ペアを独立とみなしても MDE 19.4ポイント、
> 正しい8記事クラスタでは29.0ポイントだった。過去の0〜3.3ポイント差は検出範囲外である。
> また human-human 条件が69.4%となり、raw 50%目標も未較正だった。
> 実験・数値・結論の棚卸しは
> `benchmarks/writing-tasks/jp-natural-writing/README.md` の
> 「測定器の陽性対照」と `results/2026-07-31-mde-positive-control.json` を参照。

22 設計・500 判定を回した結果、動いたのは1つだけだった。
設計を1つずつ潰し続けるより、**何を人間らしさと定義してきたか**を疑うほうが安い、
という判断でこのメモを書く。

---

## 1. これまでの暗黙の定義

全設計に共通する前提が1つある。

> **人間らしさはテキストの性質である。**

数量ノルマ・自己推敲・lint ゲート・骨格の除去/移植・生成器の混成・relay・
後処理の削除・丁寧体変換・文長分割・接続詞削除 —— 22 設計すべてが
「テキストのどの性質を動かすか」の探索だった。

結果は、表層側が完全にゼロである。

```
変異アブレーション（5条件・対応ありペア・帰無対照つき）
  帰無対照（バイト同一の再判定）   1 ペア移動   ← 床
  M5 丁寧体（最大の特徴量差を閉じた） 1 ペア移動
  M3 内省の締め削除                0
  M1+M3                          0
  M6 文長分割                     1 移動 / 1 逆行
```

特徴量の差が大きいことは、介入の価値をまったく予測しなかった。
リンク（d=1.73）ゼロ、丁寧体（人間 65.2 対 生成 0.0）ゼロ。
**テキストの性質を動かす、という枠組み自体が外れている**と考えるべき段階にある。

## 2. 実測が指している定義

勝ち講評 47 件（生成記事が人間と選ばれた試行・全実行から集計）に何が挙がっているか:

```
  39/47  相手が定型的に見えた
  37/47  実在の識別子（コミットハッシュ・テスト名）
  34/47  未解決のまま終わる
  24/47  生の数値（elapsed_s=9.525999757897807e-06 など）
  17/47  未整理・断片的
   5/47  余談を「今回の主題ではない」と切り捨てている
```

37〜5 の行を並べると、**どれもテキストの性質ではない**。全部、テキストの外に何かがある
ことの痕跡である。

| 挙がったもの | 何の痕跡か |
|---|---|
| 実在のコミットハッシュ | テキストの外を指す指示子。中身は記事に無い |
| `elapsed_s=9.525999757897807e-06` | 有効数字16桁。**作文ではなく転記**でしか出ない |
| 未解決のまま終わる | 世界の側が終わっていない。書き手の選択ではない |
| 「今回の主題ではない」と切った余談 | 記事が必要とする**以上の素材を持っていた**証拠 |
| 誤字（較正コーパスの `num_trainig_steps`） | 注意がテキストではなく世界に向いていた |

まとめるとこうなる。

> **人間らしさとは、テキストが「自分より大きい有限の世界からの標本」であることの痕跡である。**

人間は**余剰から書いて捨てる**。モデルは**不足から書いて埋める**。
読み手が検出しているのは、書かれなかったものが落とす影のほうだ。

### 具体性は機構ではない

ここが今回いちばん重要な訂正になる。これまでは「実素材 → 具体的になる → 人間らしい」と
読んでいた。だが具体性を直接足す介入（リンク注入・丁寧体・文長）はすべてゼロだった。

効いているのは具体性ではなく**有限性**である。世界が有限だから素材は尽きる（未解決の締め）、
有限だから余る（切り捨てた余談）、有限だから作文できない（転記された16桁）。

## 3. この定義は、これまでの全結果を説明する（後付けでないことの確認）

新しい定義は、既存の否定結果を1つずつ説明できなければ価値がない。

| 実測された結果 | 新しい定義からの説明 |
|---|---|
| 数量ノルマ（固有名詞3つ以上）→ 捏造 | 余剰が無いのに「捨てる真似」を要求した。無い世界からは転記できないので作文になる |
| `freewrite`（枠を全部外す）→ 不変 | 問題は枠ではない。余剰が無ければ枠を外しても埋める |
| `skeleton`（人間の骨格を移植）→ 無効果 | 骨格は影であって、影だけ置いても本体が無い |
| M4 機械的な末尾切断 → ゼロ | 切断は未解決ではない。**未解決とは「素材が尽きた」という意味論的事実**であり、文の途中で切ることではない |
| M5/リンク/文長 → ゼロ | どれも余剰の痕跡ではない |
| `writer` だけが効く | 閉じた台帳＝**有限の世界**を与えている唯一の設計 |
| 声（hedge・内省・一人称）が過剰 | モデルは不足を埋めるので、埋め草が過剰になるのは当然の帰結 |

M4 の説明が特に効く。「文の途中で終わる」は人間コーパスに実在した特徴なので当初は
有望に見えたが、実際にはゼロだった。新しい定義はこれを事前に予測する ——
切断は**世界が尽きたことの痕跡ではなく、テキストを切っただけ**だからだ。

## 4. 測定側にも定義の問題がある

勝ち講評の最頻項目は 39/47 で「相手が定型的に見えた」だった。**判定を動かしている最大の
要因は、候補ではなく対戦相手の性質である。**

いまの対戦相手は Qiita のチュートリアル・紹介記事で、生成側は作業ログである。
負け講評は相手の「見出し・箇条書き・表・画像」を人間性の根拠に挙げ、勝ち講評は同じものを
「整いすぎ」と呼ぶ。つまりこの指標は、**著者性（人間かAIか）とジャンル（作業ログか紹介記事か）を
分離できていない。**

これは 82〜94% という数字の解釈に直接効く。いま測っているものの一部は
「これは Qiita 記事らしいか」であって「これは人間が書いたか」ではない。

## 5. 新しい定義から出る実験

この定義は、これまでと**違う予測**をする。それが検証可能性の担保になる。

### E1 — 余剰比（surplus ratio）

同一のピン台帳から、記事1本が使い切れる量の **1倍 / 3倍 / 10倍** を渡して生成する。
予測：余剰が増えるほど判別が下がる（捨てる余地が生まれるため）。素材の質・著者・
主題はすべて固定し、**量だけ**を動かす。

これは今回の著者分割の結果に対する**対抗仮説**でもある。`writer_human` の台帳は
主題がミスマッチ（リリース管理 対 Python/機械学習）だった。勝ったのは著者が人間だから
ではなく、**ミスマッチゆえに余剰が大きく、捨てる場面が増えたから**かもしれない。
著者を固定して k だけ動かせば切り分く。

### E1 の実測結果（2026-07-31）— 余剰仮説は外れた

同一ピン台帳（`bb8fcf935f32`）で spine を固定し、未使用の scraps だけを 0 / 2 / 12 に振った。
素材は 3 / 5 / 15 件。基準は同じ台帳の `writer_agent`。

```
arm                判別率   騙せた試行   対応ありペア（騙せる方向/逆/不動）
writer_agent (基準)  95%      3/62      —
writer_k0 (余剰 0)   95%      3/62      0 / 0 / 31   ← 1ペアも動かない
writer_k12 (余剰12)  94%      4/62      1 / 0 / 30
writer_p0           92%      5/62      3 / 1 / 27
writer_bio          94%      4/62      2 / 1 / 28
帰無対照の床（既測）                    1/0/30 ・ 1/3/27
```

**§2 の中心予測（余剰が増えるほど判別が下がる）は外れた。** 余剰ゼロと余剰12が
判別で区別できず、余剰ゼロにいたっては基準と 31 ペア全部が一致した。

これは連鎖して効く。E2 が実在性を否定し、E1 が余剰を否定したので、
`writer_human` > `writer_agent`（6/1）を説明する機構が**ひとつも残らない**。
ペア水準 McNemar が両側 p = 0.125 で元から有意でなかったことと合わせると、
**あれはノイズだったと読むのが最も素直**である。

`writer_bio`（経歴・知識・実体験・生活習慣の台帳）も床（2/1）。
`writer_p0`（指示された未解決の除去）は 3/1 で床のわずか上だが、絶対採点でも
全アーム中最良（70.8 / 人間判定 8%）で、方向は一貫している。

### 定義はどこまで生き残ったか

**生き残った部分** — 「未解決の締めは素材由来であって指示由来ではない」は確認された。
P0 で「まとめないでください」を外しても 8/8 が未解決で終わった（「今日はそこまで。」）。
台帳が振る舞いを作っているという主張自体は正しい。

**外れた部分** — その振る舞いを**増やしても判別は動かない**。有限性は `bare`（86〜89、
判別 100%）と `writer`（92〜95）の差を作ったが、その内側では量を振っても効かない。
つまり有限性は**閾値であって連続量ではない**、というのが実測の言い分である。

### 均等充足は台帳の中でも起きる

`writer_bio` は生活習慣を 8/8 記事で使い、「土曜の午前」を複数記事で反復した。
一方「知らないこと」（Rust・Kubernetes・型システム）は **0/8 記事**で、
「詳しくない」すら一度も出なかった。

- 無知は**関連しないと表面化しない**。バグを追う記事に Kubernetes を知らないことは書けない。
  独立したリストではなく、インシデントと交差する形でしか出口が無い。
- 生活習慣はどの記事にも当てはまるので毎回1つ使われる。コミットは大半が無関係なので捨てられる。

> **台帳が均等充足を逃れるのは、エントリの大半が「使えない」ときだけである。**

有限性そのものより、**適用可能性の低さ**が効いている可能性が高い。ただし E1 が
「使えない素材を12件足す」でゼロだったので、これも量では動かない。

### E2 — 素材の偽造テスト（最優先・最も安い・最も決定的）

勝った記事の実在値を、**同じ形の非実在値**へ機械置換する。
`41f4f72` → 別の16進7桁、`elapsed_s=9.525999757897807e-06` → 別の16桁浮動小数。
他は1バイトも変えない。判定役は read-only で、そもそも実在を検証していない。

- **判別が動かなければ**：効いているのは実素材ではなく**実素材の形**である。
  封じ込めゲートも台帳も不要で、必要なのは「転記されたように見える形」だけになる。
  rig のゲート設計全体に効く結論で、しかも供給側ゲートの必要性を揺るがす。
- **判別が動けば**：判定役が検証していないのに動いた、ということになる。
  形以外の何かが実素材に乗っている（一貫性・相互参照の整合など）ことになり、
  次に測るべき対象が確定する。

**どちらに転んでも大きい。** 生成は不要、既存記事への機械置換だけで、帰無対照は較正済み。

### E2 の実測結果（2026-07-31）— 実在性は不要だった

```
                    騙せた試行   対応ありペア（騙せる方向/逆/不動）
writer_human (基準)    10/62      —
writer_human_m7        10/62      2 / 2 / 27   ← 偽造
writer_human_m8         9/62      3 / 4 / 24   ← 誤字
writer_human_null       8/62      1 / 3 / 27   ← バイト同一の再判定
```

**偽造は集計値まで完全一致。** 帰無対照のほうが基準から遠い。E4（誤字）も床の内側で、
「表層はすべてゼロ」への反証テストは反証しなかった。

分岐は「動かない」側だった。したがって：

> **判定役にとって、素材が実在する必要はない。必要なのは転記されたものの形だけである。**

§2 の定義がこれで一段締まる。**具体性でも実在性でもなく、有限性が機構である。**
有限だから尽き（未解決の締め）、有限だから余り（切り捨てた余談）、
有限だから作文できない形になる（16桁の転記）。中身が本物かどうかは、そのどれにも要らない。

供給側ゲートの正当化も組み替わる。ゲートの価値は「本物であること」ではなく、
(1) 検証する人間の読者に対する正確性、(2) 有限性の供給、の2つである。前者は文体の話ではない。

そしてこれは直前の出自結果（`writer_human` > `writer_agent`）の解釈を否定する。
実在性そのものが効かないのに、実在する人間性だけが効く筋道が無い。
残るのはノイズか、**E1 の余剰仮説**（人間台帳は主題ミスマッチゆえに捨てる場面が多かった）。
**E1 の優先度がこれで上がった。**

限界：M7 が偽造したのは講評が名指しする値（ハッシュ・高精度浮動小数）で、テスト名と
ファイルパスは実在のまま残した。結論は「証拠として挙げられる値は偽物でよい」であって
「実在するものは何ひとつ効かない」ではない。

### E3 — ジャンル統制

対戦相手を**作業ログ系の人間記事**に揃える（Qiita を「ハマった」「原因調査」「備忘録」
「解決できていない」等で引き直す）。いまの紹介記事プールでは、著者性とジャンルが交絡している。

予測：ジャンルを揃えると判別率は下がる（＝いまの 82〜94% の一部はジャンル差だった）。
下がらなければ、ジャンル交絡は無かったことが分かる。コーパスのクエリ変更だけで測れる。

### E3 の実測結果（2026-07-31）— 操作が失敗し、代わりに指標の性質が出た

Qiita を「ハマった」「原因」「備忘録」で引き直して 91 本の対戦相手を作り、同じ生成記事を
当て直した。結果は**下がるどころか上がった**（`writer_agent` 95% → 98%、`writer_p0` 92% → 94%）。

だが操作の検証を先にすべきだった。2つのコーパスを文書の型で比べると、**ほぼ同一**である:

```
                 n    はじめに見出し   画像   表    未解決で終わる
既定コーパス      48       31%        56%   13%      0%
ジャンル統制      91       44%        52%   13%      0%
```

「はじめに」見出しはむしろ増えている。Qiita の全文検索語は本文のどこかに現れれば
ヒットするので、チュートリアルの調査パートにも当たる。**ジャンルは変わっていない。**
したがって §4 のジャンル交絡は**否定されたのではなく、依然として未検証**である。

### ただし、この検証から別の数字が出た

```
未解決で終わる人間記事   0 / 139 本（両コーパス合計）
```

勝ち講評で 34/47 と2番目に多く挙げられていた「未解決のまま終わる」は、
**人間の Qiita 記事が事実上一度もやらないこと**だった。

つまり判定役は、参照集団の実際の分布に照らして人間性を判定していない。
**「人間ならこう書くはず」という規範に照らしている。** 較正（人間記事 n=16 の平均 11.06）が
保証したのは「本物の人間を人間と判定できる」ことであって、
「人間性の根拠として挙げる特徴が人間の分布と一致している」ことではなかった。

これが、なぜ何をやっても動かないのかの説明になりうる。アームは判定役の規範が報いる特徴
（実在の識別子・未解決の締め）を**すでに飽和**させており、それでも別のところで見破られている。
規範側の飽和した特徴をさらに押しても、定義上、動かない。

### E4 — 誤字注入（自分の結論への反証テスト）

較正コーパスで人間と判定された記事は誤字を含んでいた（`num_trainig_steps`、「わけでわない」）。
誤字は表層特徴だが、**プロセスの痕跡**でもある（注意がテキストに向いていなかった証拠）。

「表層はすべてゼロ」という §1 の結論は、**誤字もゼロであることを予測する**。
効いてしまえば私の結論が間違っていたことになるので、これは反証テストとして置く。
機械的に注入でき、帰無対照つきで測れる。

## 6. 順番

```
1. E2 素材の偽造        生成不要・決定的・rig 本体の設計判断に直結
2. E4 誤字注入          §1 の結論への反証。E2 と同じ枠組みで同時に回せる
3. E3 ジャンル統制      コーパスのクエリ変更のみ。指標の妥当性そのものを測る
4. E1 余剰比           生成が要る。E2/E3 で枠組みが生き残ってから
```

E2 と E4 は同一の変異アブレーション機構（`mutate.py` + `discriminate.py --opponents`）に
そのまま乗る。E3 は `fetch_human_corpus.py` のクエリだけ。**新しい装置は要らない。**

## 7. この定義が rig 本体に返すもの

「有限の世界からの標本」という定義は、日本語生成の外でも意味を持つ。

- **供給側ゲートが効く理由の一般化。** 閉じた台帳が効くのは具体性を増やすからではなく、
  生成器に**有限で、余り、尽きる世界**を与えるからである。コード生成に移すなら、
  「触ってよい API 面を絞る」だけでなく、**使い切れない量の実コンテキストを渡して選ばせる**
  ほうが効く、という予測になる。
- **受入基準の書き方。** 「〜を最低3つ」は不足を宣言する。持っていないものを要求された
  生成器は捏造で応じる。余剰を渡して**捨てさせる**ほうが、同じ検査可能性で捏造を生まない。
