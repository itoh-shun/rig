# 実用4ジャンルでの探索（教育資料 / Qiita記事 / ラジオ台本 / 対話）

`solo_judge` を実際に使いたい4つの文書種に当てた記録。2026-08-07、判定 opus-5、
参照は `results/2026-08-07-human-reference.json`（人間62本・median 4.0・帯 [3, 6]）。
生データは `results/2026-08-07-four-genre-probe.json`。

**4本とも人間の帯に届かなかった。** 教育資料・Qiita記事・ラジオ台本は本文書のために書いた
合成サンプル、対話はこのセッションで実際に送った返信そのものである。


書くにあたって、このリポジトリの実測で**効くと分かっているものだけ**を使った — 実在の数値への
接地、未解決で終える結び、自分の失敗の記載。**効かないと分かっているもの**（「はじめに」見出し、
「まとめると」、最後の全体要約、等間隔の脱線）は避けた。それでこの水準である。

### 7回では足りなかった

最初の7回のあとに2回足したら、像が変わった。

```
ラジオ台本   7回 [72,12,72,12,65,72,68]  →  追加2回 [12, 9]
Qiita記事   7回 [60,25,68,35,60,25,8]   →  追加2回 [28, 15]
```

9回で見ると台本も Qiita もほぼ半々で人間側に落ちる。`DEFAULT_REPEATS = 7` は
**二峰のテキストには不足**で、モードの比率を推定したいなら足りない。中央値だけを見て
「台本 68」と読むと、9回中4回が 12 以下だという事実を落とす。

## 2. 講評が名指ししたもの — 4本とも「形」

内容ではなく構造が一貫して挙がった。

**社内教育資料**（68点・2回とも同じ指摘）:

> 各節が「主張→箇条書き→太字の結論」という同型のリズムで整いすぎており、末尾の
> 「まだ分かっていないこと」という限界提示まで含めて構成が定型的

限界の明示すら型の一部として読まれている。もう1つは私が実際に作り込んだ欠陥を突いた —
「出典が曖昧なまま精密な数字が並ぶ」。ODL の 44%/42%/72% を報告書名も著者も書かずに置いた。
社内資料でこれをやると AI 臭以前に信用の問題になる。

**Claudeとの対話**（70点）が最も具体的だった:

> 『より重要な発見があります』『予測が外れたものがもう一つあります』『唯一の明るい材料として』
> 『正直な限界として』といった見出し的な接続句や**誠実さの定型パターン**、話し言葉らしい
> 揺れ・冗長さの欠如

接続句が実際に列挙されている。**限界を必ず最後に置き、予測の外れを必ず同じ形で認める** —
正直さに型がある。このリポジトリが「均等に演じられた人間らしさは指紋である」と記録している
現象を、誠実さの次元でやっていたことになる。

**低いほうに振れたとき**の理由は3本とも同じだった:

> 具体的な数値ログ・自らの失敗の告白・未解決のまま終わる結び・文長の不均一さ（Qiita 15点）
> 相槌の粗さや話題の逸れ方も含めて台本というより実際の会話の呼吸に近く（台本 12点）

つまり同じテキストが、**構造を見られると 68、中身を見られると 12** になる。二峰の正体は
判定役がどちらを重く見るかであって、テキストが中間にあるのではない。

## 3. 説明義務という境界

このセッションで手書きした6本を並べると、はっきりした線が1本ある。

```
説明義務なし    日記        6.0   INSIDE_HUMAN
              自由研究     20.0   UNSTABLE
説明義務あり    Qiita       35.0   UNSTABLE
              対話        65.0   OUTSIDE
              教育資料     68.0   OUTSIDE
              台本        68.0   UNSTABLE
              ニュース     74.0   OUTSIDE
```

日記は読者に何も渡さなくてよく、未解決のまま放り出せる。教育資料は読み終えた人が何か
できるようにならないと失敗する。**その義務が構造を要求し、構造が読まれる。**

ベンチのアームが8ヶ月測ってきたのは Qiita 記事、つまりこの線の重いほうである。23設計が
否定され、アーム32記事のうち帯に入ったものはゼロだった。日記の成功はここへ転用できない。

## 4. 分かっていないこと

- **参照に台本と対話がない。** 帯は Qiita 記事とブログで作ってあり、話し言葉・対話の人間文で
  較正していない。台本 68 と対話 65 は**較正範囲の外での測定**である。
- **合成サンプルである。** 4本のうち3本は本文書のために書いたもので、実務の原稿ではない。
  実素材のほうが情報が出るというのが本セッションの一貫した所見なので、実物での再測定が要る。
- **対話の構造をどう直すかの答えがない。** 「毎回構成を変える」を規則にすれば則2 が待っている
  （検査可能な要求は均等に満たされる）。台本が時々 9 点を取れたのは、話し言葉に「毎回同じ形で
  締める場所」が構造的に無いからだと考えているが、これは仮説であって測っていない。
- **n=1/ジャンル。** ジャンル差を主張できる標本数ではない。
