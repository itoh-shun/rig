# Rigを使って開発をちょっと便利にする

Rigは、AIを使った開発を支援するツールです。エージェントを使ってコードを書いたりレビューしたりできる機能があり、普通にチャットするよりも開発向けになっています。「レシピ」という仕組みを使うと、処理の内容を決めることができます。

インストールするとコマンドが使えるようになり、あとはやりたいことを入力するだけで動きます。たとえばバグを直したいときは、バグの内容を書いて実行します。レビューも自動でできるので便利です。

```sh
rig-wb run "ログイン処理のバグを直す"
```

複雑な作業では、複数のエージェントを使うこともできます。テストやレビューもやってくれるため、開発者が全部を確認しなくてもよくなります。ただし、AIが間違えることもあるので、最後は人間が確認してください。

この記事ではRigの基本的な使い方を紹介しました。興味がある方は試してみてください。
