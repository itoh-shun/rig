# Rigを使って開発をちょっと便利にする

Rigは、AIを使った開発を支援するツールです。エージェントを使ってコードを書いたりレビューしたりでき、普通にチャットで質問するよりも開発向けに作られています。処理内容を決められる「レシピ」という仕組みも用意されています。

## 使い方

インストールするとコマンドが使えるようになります。あとはやりたいことを入力するだけで動きます。たとえばバグを直したいときは、バグの内容を書いて実行します。

```sh
rig-wb run "ログイン処理のバグを直す"
```

レビューも自動で行われるため、便利です。

## 複数エージェントでの作業

複雑な作業では、複数のエージェントを使うこともできます。テストやレビューもエージェントが担ってくれるので、開発者がすべてを確認しなくてもよくなります。

## 注意点

ただし、AIが間違えることもあります。最後は人間が確認するようにしてください。
