# Rigを使って開発をちょっと便利にする

RigはAIを使った開発を支援するツールです。いろいろな機能があり、エージェントを使ってコードを書いたりレビューしたりできます。普通にチャットするよりも開発向けになっていて、レシピというものを使うと処理を決められます。

インストールするとコマンドが使えるようになるので、あとはやりたいことを入力すれば動きます。例えばバグを直したいときは、バグの内容を書いて実行します。レビューも自動でできるため、便利です。

```sh
rig-wb run "ログイン処理のバグを直す"
```

複雑な作業では複数のエージェントを使うこともできます。テストやレビューもやってくれるので、開発者が全部確認しなくてもよくなります。ただし、AIが間違えることもあるので、最後は人間が確認してください。

この記事ではRigの基本的な使い方を紹介しました。興味がある人は試してみてください。
