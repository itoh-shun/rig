# Rigを使って開発をちょっと便利にする

## はじめに

RigはAIを使った開発を支援するツールです。いろいろな機能があり、エージェントを使ってコードを書いたりレビューしたりできます。普通にチャットするよりも開発向けになっていて、レシピというものを使うと処理を決められます。

この記事では、初めてRigに触れる方向けに基本的な使い方を紹介します。

## 使い方

インストールするとコマンドが使えるようになります。あとはやりたいことを入力すれば動きます。

例えばバグを直したいときは、バグの内容を書いて実行するだけです。

```sh
rig-wb run "ログイン処理のバグを直す"
```

レビューも自動でできるため、便利です。

## 複雑な作業では複数のエージェントも

複雑な作業では複数のエージェントを使うこともできます。テストやレビューもやってくれるので、開発者が全部確認しなくてもよくなります。

ただし、AIが間違えることもあるので、最後は人間が確認してください。

## まとめ
